# GitHub Pages deployment

This repository hosts the Pip's English Adventure V5.4.2 interactive prototype.

- Public demo URL: https://joeyyangwenku.github.io/pips-english-adventure/
- Publishing source: `main` branch, `/(root)` directory
- Entry point: `index.html`
- `.nojekyll` is present to serve the static HTML directly.

The public demo URL should be shared only after GitHub Pages reports a successful deployment and the site loads in a browser.

To diagnose a 404, review **Settings → Pages** and the **Actions → pages build and deployment** workflow, confirming that the deployment completed successfully.
