# Pip's English Adventure · 项目简介

## 一句话定位

**一款为 6–8 岁儿童设计的故事驱动式英语学习原型：孩子帮助小龙 Pip 修复水晶桥，在六个循序渐进的互动活动中练习听力、基础拼读、简单表达和阅读理解，并让家长清楚看到学习过程。**

## 为什么做这个产品？

儿童英语启蒙常出现两个极端：机械练习缺少故事动力，过度游戏化又容易让孩子追求积分而忽略语言能力。Pip 将故事目标、循序渐进的教学活动和可解释的学习记录结合在一起。

## 核心差异

1. **Story with Purpose / 故事有学习目标：** 六项英语任务帮助 Pip 找回水晶并修复水晶桥。
2. **Progressive Practice / 任务循序渐进：** 听辨颜色与物品 → 执行指令 → 两步指令 → CVC 拼读 → 组句 → 阅读线索。
3. **Live Learning Evidence / 动态学习证据：** Lesson Map 和 Learning Evidence 随选择、答错、重试、通过而变化；记录尝试次数与首次正确情况。
4. **Child-first & Parent-friendly / 双视角：** 儿童界面英文优先，中文家长报告帮助理解学习过程。

## 使用流程

开场介绍 → 六关总览 → 当前英语活动（左栏）与学习地图/证据（右栏）→ 完成六关 → 中文家长报告。

## 当前阶段与局限

- 版本：V5.4.2 交互式早期原型；建议在电脑和平板浏览器测试。
- 当前英语音频使用浏览器内建语音合成，不是真人录音。
- 不进行儿童录音，也不提供可靠的口语发音评分。
- 六星表示活动完成，不代表独立认证的英语能力或长期掌握。
- 当前课程尚未完成真实家庭样本的教学成效验证。
- 品牌与角色美术仍是原型素材，商业化前需另行确认使用权利。

## 下一步验证

观察孩子能否独立理解指令、是否愿意再次练习，以及家长是否能通过学习记录获得有效反馈；再推进真人配音、稳定角色素材和后续单元课程。
