## Upload remaining video

1. Download the enhanced MP4 from the ChatGPT project conversation.
2. On GitHub use **Add file → Upload files** in this `promo` folder (or GitHub Desktop).
3. Rename/upload it as **`promo/pip_10s_intro.mp4`**.
4. Confirm the GitHub file view can play/download it; only then add a public video link to README or the submission form.
